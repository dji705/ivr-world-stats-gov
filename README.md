# מערכת מידע טלפונית — פרטי רכב, תו נכה ומפלס הכינרת

מאגר זה מפעיל API ב־Vercel עבור מערכת IVR של ימות המשיח.

- מאגר GitHub: https://github.com/dji705/ivr-world-stats-gov
- כתובת ה־API של ימות: https://ivr-world-stats-gov.vercel.app/api/yemot
- מקור הנתונים: data.gov.il
- שירותים: פרטי רכב, בדיקת תו נכה לרכב, מפלס הכינרת.

## 1. הגדרת API

בכל אחת משלוחות ה־API יש להגדיר בקובץ ext.ini:

    type=api
    api_link=https://ivr-world-stats-gov.vercel.app/api/yemot

## 2. תפריט חדש — הפרדה בין בחירת שירות להזנת מספר

הקוד ב־api/yemot.js תומך בזרימה רב־שלבית באמצעות שלוחה ראשית ושתי שלוחות קלט נפרדות.

    שלוחה ראשית
    ├── 1 — בדיקת פרטי רכב → מעבר לשלוחה 81
    ├── 2 — בדיקת תו נכה → מעבר לשלוחה 82
    └── 3 — השמעת מפלס הכינרת

    שלוחה 81 — קלט מספר רישוי לרכב
    ├── המערכת מבקשת מספר רישוי
    ├── המתקשר מקיש 5–9 ספרות ומסיים ב־#
    ├── המערכת מחפשת את הרכב ומקריאה את הפרטים
    └── לאחר התוצאה חוזרים לשלוחת האב

    שלוחה 82 — קלט מספר רישוי לתו נכה
    ├── המערכת מבקשת מספר רישוי
    ├── המתקשר מקיש 5–9 ספרות ומסיים ב־#
    ├── המערכת בודקת את מאגר תווי הנכה
    └── לאחר התוצאה חוזרים לשלוחת האב

### הגדרות חשובות במערכת ימות

1. יש ליצור בפועל את שלוחות 81 ו־82 תחת שלוחת התפריט הראשית (או להתאים את מספריהן בקוד למבנה השלוחות בפועל).
2. להגדיר את אותו api_link בכל שלוש השלוחות: הראשית, 81 ו־82.
3. לוודא ששלוחת הקלט מוגדרת לקבלת ספרות ולהשתמש ב־# לסיום הקלט.
4. הקוד מקבל את הקלט מהפרמטרים ApiPhoneInput, Digits, val או plate.
5. קלט מספר הרכב נשאר מספרי. מפת ה־T9 שהמשתמש סיפק מיועדת לתרגום רצפי מקשים לאותיות; אין להמיר בעזרתה את ספרות מספר הרכב.
6. אם מספרי השלוחות אצלך שונים, צריך לשנות את 81 ו־82 בקוד בהתאם.

## 3. פורמט התשובה הקולית

ה־API מחזיר טקסט בפורמט של ימות המשיח, למשל:

    read=t-ברוכים הבאים למערכת המידע הטלפונית=wm_nav,no,1,1,5,Digits,no,no,,,1,Ok

הפקודה מבקשת מהמערכת להשמיע את ההודעה ולקבל קלט מהמקשים. יש לבדוק בשיחת ניסיון שהפרמטרים תואמים להגדרות השלוחה בפועל.

## 5. נתיבי API

| נתיב | תפקיד |
|---|---|
| GET /api/yemot | תגובת טקסט בפורמט של ימות המשיח |
| GET /api/vehicle?plate=1234567 | פרטי רכב ב־JSON |
| GET /api/disability-badge?plate=1234567 | בדיקת תו נכה ב־JSON |
| GET /api/kinneret | מפלס הכינרת ב־JSON |

מספר הרישוי חייב להכיל בין 5 ל־9 ספרות. התוצאות תלויות בזמינות ובתוכן של מקור הנתונים הממשלתי.

## 6. שדות פרטי רכב

הקוד יכול להקריא שדות זמינים מתוך הרשומה, ובהם:

- מספר רישוי
- קוד יצרן וסוג הדגם
- יצרן הרכב ושם הדגם
- רמת גימור ורמת אבזור בטיחותי
- דרגת זיהום אוויר
- שנת ייצור ודגם מנוע
- תאריך טסט אחרון ותוקף רישיון
- סוג בעלות ומספר שלדה
- צבע הרכב
- מידות צמיגים קדמיים ואחוריים
- סוג דלק
- תאריך עלייה לכביש ושם מסחרי

רק שדות שמוחזרים בפועל ממקור הנתונים יופיעו בתוצאה.

## 7. קבצים חשובים

- api/yemot.js — תפריט, קבלת הקלט, ניווט לשלוחות והקראת התוצאות.
- api/_lib/data.js — מזהי המאגרים, שדות הרכב, בקשות למקור הנתונים ובדיקת מספר רישוי.
- api/_lib/yemot.js — עיצוב מספרים, פיצול טקסט למקטעי הקראה וחישוב שלוחת האב.
- README.md — תיעוד הפרויקט והגדרות השלוחות.

## 8. בדיקה לפני הפעלה

1. ודאו שהפרויקט נפרס בהצלחה ב־Vercel.
2. בדקו את /api/kinneret, את /api/vehicle?plate=1234567 ואת /api/yemot.
3. צרו והגדירו את שלוחות 81 ו־82 במערכת ימות.
4. בצעו שיחת ניסיון: בחרו 1 או 2, ודאו שהמערכת עוברת לשלוחה הנכונה, בקשו מספר רישוי, הקישו אותו וסיימו ב־#.
5. בדקו שהמערכת מקריאה את התוצאה וחוזרת לשלוחת האב.

הערה: עד לביצוע שיחת ניסיון אמיתית, אין לראות בזרימת השיחה מאומתת. שינוי הקוד ב־GitHub אינו מבטיח שהפריסה ב־Vercel הסתיימה או שהגדרות השלוחות הוגדרו בחשבון ימות.
